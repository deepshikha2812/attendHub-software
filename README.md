# System Analysis
## Overview
This directory contains the system analysis and requirements modelling documentation 
for the Student Self-Attendance Tracker.

The system enables students to maintain subject-wise attendance records, manage weekly timetables, 
record class status and monitor attendance against individually defined criteria.

## Diagrams
Use Case Diagram : Illustrates the student's interactions with the system and its functionalities. |
DFD Level 0 : Represents the system as a single process and its interaction with the student. |
DFD Level 1 : Decomposes the system into its primary processes and data stores. |
Activity Diagram : Illustrates the workflow for attendance tracking and monitoring. |

## Feasibility Study
The feasibility study evaluates the proposed system across technical, 
economic, operational, legal and schedule feasibility.

## Scope
The analysis covers student account management, subject management, weekly timetable configuration, daily attendance 
marking (Attended, Missed and Off), attendance calculation, threshold monitoring and attendance alerts.
